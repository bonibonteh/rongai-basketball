Rongai Basketball Tournament website

index.html            the page
css/styles.css        styles
js/tailwind-config.js Tailwind colours and fonts
js/app.js             all site logic (scores, brackets, voting, registration)

Open index.html in a browser, or upload this whole folder to any web host
(Netlify, GitHub Pages, etc). It needs internet to load Tailwind, Lucide icons
and Google Fonts.
